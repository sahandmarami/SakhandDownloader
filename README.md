## معرفی

Download Manager یک اپلیکیشن اندروید مدرن است که با موتور دانلود **چندتردی ۳۲ کاناله** فایل‌ها را با سرعتی چند برابر بیشتر از دانلود مرورگر دریافت می‌کند. رابط کاربری کاملاً **فارسی و راست‌چین** با گرادیان بنفش-آبی طراحی شده است و همه‌چیز در دو صفحه ساده جمع شده است. از نسخه ۱٫۲ دو **تم روشن و تیره** در دسترس است و انتخاب شما به‌خاطر سپرده می‌شود.

## امکانات

- **دو تم روشن و تیره:** انتخاب تم از صفحه «درباره ما»، هماهنگی خودکار رنگ نوار وضعیت و ذخیره انتخاب
- **شتاب‌دهی دانلود:** تقسیم فایل به تا ۳۲ بخش و دانلود همزمان (اگر سرور پشتیبانی کند)
- **توقف / ادامه / لغو:** در هر لحظه، حتی بعد از بستن اپ (وضعیت روی دیسک ذخیره می‌شود)
- **نوتیفیکیشن زنده:** نمایش درصد، سرعت لحظه‌ای و دکمه‌های توقف/ادامه/لغو روی نوتیف
- **دانلود از شبکه‌های اجتماعی:**
  - یوتیوب: ویدیو با انتخاب کیفیت (بهترین / 1080p / 720p / 480p) یا فقط صدا
  - اینستاگرام: ریلز، پست و IGTV از حساب‌های عمومی
  - پینترست: عکس و ویدیو به‌صورت مستقیم و بدون واسطه
- **دانلود مستقیم از همه سایت‌ها:** کافیست لینک فایل را وارد کنید
- **ذخیره در پوشه Download عمومی** حافظه گوشی
- رزرو فضا از قبل، تلاش مجدد خودکار هنگام قطعی شبکه، سرعت‌سنج با میانگین‌گیری هوشمند

## نحوه اجرا

1. پوشه پروژه را Extract کنید.
2. Android Studio → **File > Open** → پوشه `SakhandDownloadManager` را انتخاب کنید.
3. اگر سوال پرسید که Gradle Wrapper وجود ندارد، گزینه **Use Gradle from: 'gradle-wrapper.properties' file** یا گزینه پیشنهادی خود استودیو را انتخاب کنید تا Gradle 8.7 خودکار دانلود شود.
4. صبر کنید تا Sync تمام شود (بار اول چند دقیقه طول می‌کشد).
5. گوشی را با USB وصل کنید (حالت USB Debugging فعال) یا یک شبیه‌ساز بسازید و **Run** بزنید.

### ساخت APK خروجی

- منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)**

- برای نسخه نهایی: **Build > Generate Signed Bundle / APK** و ساخت یک keystore شخصی

## تنظیم بخش شبکه‌های اجتماعی (مهم)

دانلود یوتیوب و اینستاگرام از طریق سرویس متن‌باز **Cobalt** انجام می‌شود. اپ به‌صورت خودکار چند سرور عمومی را **به‌صورت همزمان** امتحان می‌کند و اولین پاسخ موفق را استفاده می‌کند. اگر می‌خواهید سرور شخصی خودتان اولویت داشته باشد، فایل زیر را باز کنید:

```
app/src/main/java/com/sakhand/downloadmanager/social/SocialResolver.kt
```

دو ثابت بالای کلاس:

```kotlin
private const val CUSTOM_ENDPOINT = "https://your-cobalt-server.com/"
private const val CUSTOM_API_KEY = ""
```

- سرورهای عمومی ممکن است هر زمان محدودیت یا نیاز به کلید داشته باشند (در این صورت اپ پیام راهنما نشان می‌دهد).
- برای تجربه پایدار و بدون محدودیت، می‌توانید **سرور شخصی کوبالت** راه بیندازید (مثلاً با Docker: مخزن `imputnet/cobalt`) و آدرسش را در `CUSTOM_ENDPOINT` بگذارید. اگر کلید API دارید در `CUSTOM_API_KEY` قرار دهید.
- **پینترست نیازی به این سرویس ندارد** و مستقیم دانلود می‌شود (ویدیو از API داخلی پینترست + تحلیل HTML صفحه، با چند لایه پشتیبان).

## معماری پروژه

```
app/src/main/java/com/sakhand/downloadmanager/
├── App.kt                    ← مقداردهی اولیه
├── MainActivity.kt           ← ورود به اپ + مجوزها + RTL فارسی
├── data/Models.kt            ← مدل‌ها (DownloadItem, ChunkState, ...)
├── engine/
│   ├── DownloadManager.kt    ← موتور دانلود چندتردی ۳۲ کاناله + توقف/ادامه
│   ├── DownloadService.kt    ← سرویس پیش‌زمینه + نوتیفیکیشن پیشرفت
│   └── StorageSaver.kt       ← ذخیره در پوشه Download (MediaStore / legacy)
├── social/
│   ├── SocialDetector.kt     ← تشخیص خودکار پلتفرم از لینک
│   └── SocialResolver.kt     ← استخراج لینک مستقیم (کوبالت چندسروری + پینترست مستقیم)
├── ui/
│   ├── AppRoot.kt            ← نویگیشن دو تب ساده
│   ├── theme/                ← تم روشن و تیره + فونت وزیرمتن
│   ├── components/           ← کارت دانلود، دکمه گرادیانی، ...
│   └── screens/              ← خانه (با تشخیص خودکار لینک)، دانلودها، درباره ما
└── util/Format.kt            ← قالب‌بندی فارسی اعداد و حجم
```

## نکات فنی

- **minSdk 26 / targetSdk 34** — سازگار از اندروید ۸ تا ۱۴
- اندروید ۱۰+: ذخیره با `MediaStore.Downloads` بدون هیچ مجوز حافظه
- اندروید ۸ و ۹: مجوز `WRITE_EXTERNAL_STORAGE` در اولین اجرا گرفته می‌شود
- نوتیفیکیشن روی اندروید ۱۳+ مجوز `POST_NOTIFICATIONS` می‌خواهد
- فایل‌های نیمه‌کاره با پسوند `.part` به‌همراه فایل وضعیت بخش‌ها در حافظه اختصاصی اپ نگهداری می‌شوند تا ادامه دانلود ممکن باشد
- محدودیت سیستمی اندروید ۱۴: سرویس‌های dataSync حداکثر ~۶ ساعت در روز می‌توانند فعال بمانند

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| Sync نمی‌شود | منوی File > Sync Project with Gradle Files؛ اتصال اینترنت برای دانلود وابستگی‌ها لازم است |
| «سرور استخراج به کلید دسترسی نیاز دارد» | طبق بخش «تنظیم بخش شبکه‌های اجتماعی» یک سرور شخصی کوبالت تنظیم کنید |
| دانلود چندتردی انجام نمی‌شود | بعضی سرورها `Accept-Ranges` ندارند؛ اپ خودکار به دانلود تک‌کاناله برمی‌گردد |
| فایل در گالری دیده نمی‌شود | پوشه `Download` را با هر فایل‌منیجری ببینید؛ تصاویر بعد از MediaScan ظاهر می‌شوند |

## اطلاعات بیلد و امضا

این پروژه با موفقیت کامپایل شده و دو خروجی APK آماده دارد:

| خروجی | حجم | کاربرد |
|---|---|---|
| `SakhandDownloader-v1.3-release.apk` | ~2.0MB | نصب نهایی — فشرده‌شده با R8، امضاشده |
| `SakhandDownloader-v1.3-debug.apk` | ~17.6MB | تست و دیباگ |

برای بیلد مجدد از خط فرمان:

```bash
./gradlew assembleDebug     # نسخه دیباگ
./gradle assembleRelease    # نسخه ریلیز امضاشده
```

### کلید امضا (Keystore)

فایل `sakhand-release.keystore` در ریشه پروژه قرار دارد و نسخه ریلیز با آن امضا می‌شود:

- **Alias:** `sakhand`
- **Store/Key password:** `sakhand1404`
- **CN:** Sakhand Morami

⚠️ **مهم:** برای انتشار نسخه‌های بعدی (آپدیت) حتماً از همین keystore استفاده کنید، وگرنه اندروید اجازه نصب نسخه جدید روی نسخه قبلی را نمی‌دهد. این فایل را در جای امنی نگه دارید و آن را در گیت کامیت نکنید. برای انتشار عمومی بهتر است رمز عبور را عوض کنید:

```bash
keytool -storepasswd -keystore sakhand-release.keystore -new YOUR_NEW_PASSWORD
```
