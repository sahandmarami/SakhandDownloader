## معرفی

Download Manager در دو نسخه عرضه می‌شود:

- **نسخه اندروید** (Kotlin + Jetpack Compose) — خروجی APK
- **نسخه ویندوز** (C#‎ + .NET 8 + Avalonia UI) — خروجی exe تک‌فایلی، بدون نیاز به نصب

هر دو نسخه با موتور دانلود **چندتردی ۳۲ کاناله** فایل‌ها را با سرعتی چند برابر بیشتر از دانلود معمولی دریافت می‌کنند. رابط کاربری کاملاً **فارسی و راست‌چین** با گرادیان بنفش-آبی طراحی شده است و همه‌چیز در دو صفحه ساده جمع شده است. دو **تم روشن و تیره** در دسترس است و انتخاب شما به‌خاطر سپرده می‌شود.

## امکانات

- **دو تم روشن و تیره:** انتخاب تم از صفحه «درباره ما» و ذخیره انتخاب
- **باز کردن پوشه:** بعد از اتمام دانلود، با یک کلیک پوشه دانلود باز و فایل انتخاب می‌شود (نسخه ویندوز)
- **تغییر نام فایل:** ردیف‌های تمام‌شده یا متوقف را می‌توان بدون دردسر تغییر نام داد (نسخه ویندوز)
- **شتاب‌دهی دانلود:** تقسیم فایل به تا ۳۲ بخش و دانلود همزمان (اگر سرور پشتیبانی کند)
- **توقف / ادامه / لغو:** در هر لحظه، حتی بعد از بستن اپ (وضعیت روی دیسک ذخیره می‌شود)
- **نوتیفیکیشن زنده:** نمایش درصد، سرعت لحظه‌ای و دکمه‌های توقف/ادامه/لغو روی نوتیف
- **دانلود از شبکه‌های اجتماعی:**
  - یوتیوب: ویدیو با انتخاب کیفیت (بهترین / 1080p / 720p / 480p) یا فقط صدا
  - اینستاگرام: ریلز، پست و IGTV از حساب‌های عمومی
  - پینترست: عکس و ویدیو به‌صورت مستقیم و بدون واسطه
- **دانلود مستقیم از همه سایت‌ها:** کافیست لینک فایل را وارد کنید
- **ذخیره در پوشه Download عمومی** حافظه گوشی
- رزرو فضا از قبل، تلاش مجدد خودکار هنگام قطعی شبکه، سرعت‌سنج با میانگین‌گیری هوشمند

## نحوه اجرا

1. پوشه پروژه را Extract کنید.
2. Android Studio → **File > Open** → پوشه `SakhandDownloadManager` را انتخاب کنید.
3. اگر سوال پرسید که Gradle Wrapper وجود ندارد، گزینه **Use Gradle from: 'gradle-wrapper.properties' file** یا گزینه پیشنهادی خود استودیو را انتخاب کنید تا Gradle 8.7 خودکار دانلود شود.
4. صبر کنید تا Sync تمام شود (بار اول چند دقیقه طول می‌کشد).
5. گوشی را با USB وصل کنید (حالت USB Debugging فعال) یا یک شبیه‌ساز بسازید و **Run** بزنید.

### ساخت APK خروجی

- منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)**
- خروجی در مسیر: `app/build/outputs/apk/debug/app-debug.apk`
- برای نسخه نهایی: **Build > Generate Signed Bundle / APK** و ساخت یک keystore شخصی

## تنظیم بخش شبکه‌های اجتماعی (مهم)

دانلود یوتیوب و اینستاگرام از طریق سرویس متن‌باز **Cobalt** انجام می‌شود. اپ به‌صورت خودکار چند سرور عمومی را **به‌صورت همزمان** امتحان می‌کند و اولین پاسخ موفق را استفاده می‌کند. اگر می‌خواهید سرور شخصی خودتان اولویت داشته باشد، فایل زیر را باز کنید:

```
app/src/main/java/com/sakhand/downloadmanager/social/SocialResolver.kt
```

دو ثابت بالای کلاس:

```kotlin
private const val CUSTOM_ENDPOINT = "https://your-cobalt-server.com/"
private const val CUSTOM_API_KEY = ""
```

- سرورهای عمومی ممکن است هر زمان محدودیت یا نیاز به کلید داشته باشند (در این صورت اپ پیام راهنما نشان می‌دهد).
- برای تجربه پایدار و بدون محدودیت، می‌توانید **سرور شخصی کوبالت** راه بیندازید (مثلاً با Docker: مخزن `imputnet/cobalt`) و آدرسش را در `CUSTOM_ENDPOINT` بگذارید. اگر کلید API دارید در `CUSTOM_API_KEY` قرار دهید.
- **پینترست نیازی به این سرویس ندارد** و مستقیم دانلود می‌شود (ویدیو از API داخلی پینترست + تحلیل HTML صفحه، با چند لایه پشتیبان).

## معماری پروژه

```

├── MainActivity.kt           ← ورود به اپ + مجوزها + RTL فارسی
├── data/Models.kt            ← مدل‌ها (DownloadItem, ChunkState, ...)

│   ├── DownloadManager.kt    ← موتور دانلود چندتردی ۳۲ کاناله + توقف/ادامه
│   ├── DownloadService.kt    ← سرویس پیش‌زمینه + نوتیفیکیشن پیشرفت
│   └── StorageSaver.kt       ← ذخیره در پوشه Download (MediaStore / legacy)
├── social/
│   ├── SocialDetector.kt     ← تشخیص خودکار پلتفرم از لینک
│   └── SocialResolver.kt     ← استخراج لینک مستقیم (کوبالت چندسروری + پینترست مستقیم)
├── ui/
│   ├── AppRoot.kt            ← نویگیشن دو تب ساده
│   ├── theme/                ← تم روشن و تیره + فونت وزیرمتن
│   ├── components/           ← کارت دانلود، دکمه گرادیانی، ...
│   └── screens/              ← خانه (با تشخیص خودکار لینک)، دانلودها، درباره ما
└── util/Format.kt            ← قالب‌بندی فارسی اعداد و حجم
```

## تغییرات نسخه ۱.۶ — اینستاگرام مطمئن‌تر

- **سرور جدید تأییدشده:** یک سرور عمومی دیگر که اینستاگرام را واقعاً پردازش می‌کند به فهرست اضافه شد (پست عکس/ویدیو/چندرسانه‌ای) — روی همین نسخهٔ ۱.۵ هم از راه دور اعمال شد
- **پشتیبانی از پست چندرسانه‌ای و عکس:** پاسخ picker سرورها حالا درست مدیریت می‌شود
- **فهرست تمیز سرورها:** فقط سرورهای فعال و تست‌شده در لیست هستند
- **زمان‌بندی پایدارتر:** مهلت اتصال برای شبکه‌های موبایل آهسته بیشتر شد

## تغییرات نسخه ۱.۵ — معماری خودترمیم برای دانلود

- **تنظیمات ریموت سرورها:** لیست سرورهای استخراج دیگر داخل برنامه ثابت نیست؛ برنامه آن را از اینترنت می‌خواند. اگر سروری از کار بیفتد، لیست از راه دور به‌روز می‌شود و **بدون نیاز به نصب نسخهٔ جدید** تعمیر می‌شود
- **سه لایه پشتیبان برای یوتیوب:** کوبالت → Piped (با لینک پروکسی‌شده و LBRY) → Invidious؛ حتی وقتی همهٔ سرورهای استخراج مشکل داشته باشند، دانلود از مسیرهای مستقل ادامه دارد
- **مسیر مستقیم اینستاگرام:** پست و ریل حالا از API مستقیم اینستاگرام (رمزگشایی محلی شناسه رسانه از shortcode + دو هاست + GraphQL) استخراج می‌شود — مستقل از سرورهای واسط
- **استوری و هایلایت:** زنجیرهٔ مستقیم با دو هاست و دو روش ورود تقویت شد
- **پیام‌های خطای راهنما:** اگر مشکل از فیلترشکن باشد، برنامه دقیقاً توضیح می‌دهد چه کاری باید انجام شود

## تغییرات نسخه ۱.۴ — رفع مشکل یوتیوب و اینستاگرام

- **رفع خطای دانلود بعضی ویدیوهای یوتیوب:** موتور استخراج با زنجیره پشتیبان جدید بازسازی شد؛ اگر سرورهای کوبالت برای ویدیویی جواب ندهند (محدودیت یوتیوب روی سرورهای اشتراکی)، برنامه به‌صورت خودکار از مسیر مستقل **Piped** استفاده می‌کند
- **ارتقای سرورهای کوبالت:** سرورهای ازکارافتاده حذف و سرورهای فعال جدید جایگزین شدند
- **پشتیبان مستقیم اینستاگرام:** برای پست و ریل، بعد از شکست سرورها مسیر GraphQL بدون ورود امتحان می‌شود
- **پشتیبانی استوری/هایلایت اینستاگرام:** لینک‌های `stories/` و `highlights/` حالا از زنجیره مستقیم API موبایل اینستاگرام استخراج می‌شوند (بسته به محدودیت اینستاگرام روی حساب‌های خصوصی ممکن است بعضی استوری‌ها قابل دانلود نباشند)
- پیام‌های خطای دقیق‌تر فارسی برای محدودیت‌های سنی، خصوصی و محدودیت نرخ

## نکات فنی

- **minSdk 26 / targetSdk 34** — سازگار از اندروید ۸ تا ۱۴
- اندروید ۱۰+: ذخیره با `MediaStore.Downloads` بدون هیچ مجوز حافظه
- اندروید ۸ و ۹: مجوز `WRITE_EXTERNAL_STORAGE` در اولین اجرا گرفته می‌شود
- نوتیفیکیشن روی اندروید ۱۳+ مجوز `POST_NOTIFICATIONS` می‌خواهد
- فایل‌های نیمه‌کاره با پسوند `.part` به‌همراه فایل وضعیت بخش‌ها در حافظه اختصاصی اپ نگهداری می‌شوند تا ادامه دانلود ممکن باشد
- محدودیت سیستمی اندروید ۱۴: سرویس‌های dataSync حداکثر ~۶ ساعت در روز می‌توانند فعال بمانند

### اندروید

| خروجی | حجم | کاربرد |
|---|---|---|
| `SakhandDownloader-v1.6-release.apk` | ~2.0MB | نصب نهایی — فشرده‌شده با R8، امضاشده |

برای بیلد مجدد از خط فرمان:

```bash
./gradlew assembleDebug     # نسخه دیباگ
./gradle assembleRelease    # نسخه ریلیز امضاشده
```

### ویندوز (C#‎ + .NET 8 + Avalonia UI)

سورس نسخه ویندوز در پوشه `windows/SakhandDm` قرار دارد و مستقیماً با **Visual Studio 2022** (با ورک‌لود .NET desktop) یا VS Code باز می‌شود.

```bash
# اجرا
dotnet run --project windows/SakhandDm

# خروجی تک‌فایلی ویندوز (بدون نیاز به نصب .NET روی سیستم مقصد)
dotnet publish windows/SakhandDm -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true
```

| خروجی | حجم | کاربرد |
|---|---|---|
| `SakhandDownloader-v1.3-win-x64.exe` | ~45MB | اجرای مستقیم روی ویندوز ۱۰/۱۱ — نیازی به نصب ندارد |

نکته‌های نسخه ویندوز:
- رابط کاملاً بازطراحی‌شده — دقیقاً مثل نسخه اندروید: هدر گرادیانی متحرک، تب‌های پایین با آیکون، کارت‌های دانلود با آیکون وضعیت، صفحه درباره یکسان و تم روشن/تیره هماهنگ
- فایل‌ها در پوشه `Downloads` ویندوز ذخیره می‌شوند
- دکمه «باز کردن پوشه» فایل را در Explorer انتخاب می‌کند
- «تغییر نام» هم برای فایل تمام‌شده کار می‌کند و هم دانلود متوقف‌شده
- وضعیت دانلودها بین اجراها ذخیره می‌شود (`%LOCALAPPDATA%\SakhandDownloadManager`)

### کلید امضا (Keystore)

فایل `sakhand-release.keystore` در ریشه پروژه قرار دارد و نسخه ریلیز با آن امضا می‌شود:

- **Alias:** `sakhand`
- **Store/Key password:** `sakhand1404`
- **CN:** Sakhand Morami

⚠️ **مهم:** برای انتشار نسخه‌های بعدی (آپدیت) حتماً از همین keystore استفاده کنید، وگرنه اندروید اجازه نصب نسخه جدید روی نسخه قبلی را نمی‌دهد. این فایل را در جای امنی نگه دارید و آن را در گیت کامیت نکنید. برای انتشار عمومی بهتر است رمز عبور را عوض کنید:

```bash
keytool -storepasswd -keystore sakhand-release.keystore -new YOUR_NEW_PASSWORD
```
